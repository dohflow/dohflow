## Before you start — settings

| Setting | Value |
|---|---|
| **Style** | **Vector Illustration** (must be vector — raster upscaled is not SVG and dies at 16 px) |
| **Aspect** | **1:1 square** |
| **Colours** | `#006341` emerald. Add `#DB8F6B` terracotta only for the two-colour experiments (K, L) |
| **Background** | Transparent if offered |

### What to upload as reference

**For this session: nothing.** You want *variance* right now, and a reference
image collapses it — every output starts resembling the thing you uploaded.

Upload references in **session 2**, once you have a direction worth pushing on.
At that point, feed back your own best output as a style reference and ask for
variations of it.

**Never upload:** anything from the app, any screenshot containing financial
figures, or anything from the vault. There is no reason to, and Recraft is a
third party.

Ten are single-colour and safe at 16 px. Two are deliberately riskier.
**Generate all twelve before judging any of them** — first impressions on logo
work are unreliable, and the point of a sprint is a pool, not a pick.

## The loop

1. Run all twelve. Each generation returns several results — keep anything with
   promise, bin the rest fast.
2. For directions that show life, re-run with small wording changes. That is how
   you get from twelve prompts to a pool of 40–60.
3. **Then stop generating and start judging.** Shortlist 3.
4. **Test each at 16 px and 1024 px.** This is the step people skip and regret —
   a mark that only works large is not a logo.
5. Export the shortlist as SVG.

## Two things to watch

**Recraft will sneak text in** despite the negative list. Discard those
immediately rather than planning to crop — the wordmark is typeset in Nunito by
hand and a model-drawn letterform will not match it.

**Beware the vessel that is just a bowl.** Several of these can converge on a
generic bowl icon with nothing of the brand in it. If a candidate would work
equally well for a soup company, it is not the mark.
